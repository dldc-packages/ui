# @dldc/ui-base

> Re-exporting BaseUI components with default render prop set to @dldc/ui-components versions

Note that `render` prop won't override the `@dldc/ui-components` version but instead compose with it. If you don't want the `@dldc/ui-components` version to be used, you can use BaseUI components directly.

_Note_: This library is not developed yet as the focus is currently on Ariakit.
